# Privacy — development preview
The bundled analyzer reads local files selected by the user. It does not upload customer files, call LLM APIs, connect to databases or run customer Python code. Cell values are masked in findings. Column labels and row coordinates are included; these can themselves be sensitive. Generated reports remain local and should be handled under the user's own access rules. The selected Python interpreter is trusted by the user; isolated mode prevents importing project modules but cannot make a malicious interpreter safe. JetBrains/IDE platform services have their own privacy terms.
